# Perseid

The native desktop workbench for Perseid. It embeds the `perseid-proxy`
library and provides the Burp-style Target/Proxy/Intruder/Repeater workspace,
editable interception, editable Repeater tabs with direct replay, scope and
match/replace controls, bounded in-memory history, site map, and message
inspector.

This crate is the application binary; the proxy is available separately as
[`perseid-proxy`](https://github.com/andyintheshell/perseid/tree/main/crates/perseid-proxy).

See the [repository README](https://github.com/andyintheshell/perseid) for
setup, safety guidance, and the current feature set.
